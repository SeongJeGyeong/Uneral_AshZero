# 소개
Kog 산학 협력을 통해 Return Alive 리소스를 활용한 언리얼 엔진 게임 프로젝트입니다.

+ 개발 환경 : UE 5.5, SVN, Jira
+ 플랫폼 : PC
+ 개발 인원 : 프로그래밍 3명, 기획 5명, 아트 6명
